# MediCare Hospital

A responsive hospital website built with React + Vite.

## Run locally

```bash
npm install
npm run dev
```

Open the localhost URL shown by Vite, usually:

http://localhost:5173/

## Pages

- Home
- About
- Doctors
- Departments
- Appointment
- Contact
- Login
- Register

This is a frontend portfolio project. Appointment and registration demos use localStorage; no backend is included yet.
